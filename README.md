# Автопостинг товаров (Яндекс.Диск → Telegram + VK), без ручной сортировки

Просто закидывайте фото в папку `to_post` на Яндекс.Диске **вперемешку**,
без всякой сортировки по подпапкам. Раз в день скрипт:

1. Скачивает все ещё не опубликованные фото.
2. Показывает их все разом нейросети и просит определить, какие фото —
   один и тот же товар (по картинке + времени съёмки из EXIF как
   подсказка).
3. Берёт самую раннюю по времени группу — это сегодняшний пост,
   остальное остаётся на следующие запуски.
4. Просит нейросеть написать заголовок/описание/призыв по фиксированному
   шаблону (блок преимуществ и подпись — не от нейросети, а зашиты в
   скрипте, чтобы стиль не "плыл").
5. Публикует альбом (или одно фото) в Telegram-канал.
6. Добавляет запись в RSS-ленту (`docs/feed.xml`) — обычный импорт, без
   режима "статья", чтобы пост в VK был обычным постом с фото-обложкой,
   а не отдельной страницей, на которую нужно кликать.
7. Переносит опубликованные фото из `to_post` в `posted`.

## Шаблон поста

Нейросеть пишет только переменные части:

```
{заголовок с эмодзи}

{описание конкретно по фото}

🔥 не трескается
☔️ спокойно переносит стирки
🎨 сохраняет яркость и детали

{призыв прислать свой дизайн}

📩 Присылай изображение в сообщения — обсудим и сделаем.
✨ Custom Studio — носи то, что нравится тебе.
```

Нейросеть **никогда не указывает цену**. Если нужно продавать с ценой —
дописывайте её в пост вручную после автопубикации.

## В Telegram — альбом, в VK — одно фото-обложка

- **Telegram**: если нейросеть сгруппировала несколько фото одного
  товара — уходит полноценным альбомом.
- **VK**: через RSS всегда одно фото на пост (обычный импорт, не
  "статья") — это обычный, привычный формат поста в ленте, без перехода
  на отдельную страницу.

## Ограничение размера группы

Одна группа (один пост) — не больше `MAX_PHOTOS_PER_POST` фото
(по умолчанию 4). Это ограничение задано и в самой инструкции для
нейросети, и отдельно проверяется в коде — если нейросеть вдруг
предложит группу больше, скрипт сам обрежет её до 4 самых ранних по
времени съёмки фото, а лишние останутся в `to_post` до следующего
запуска (и снова попадут на рассмотрение).

## Важно про группировку

Нейросеть анализирует **все** ещё не опубликованные фото в `to_post` за
один запрос — если там будет очень много фото сразу (десятки), это
дороже по токенам и менее точно. Комфортный объём — до
`MAX_PHOTOS_PER_GROUPING_CALL` (по умолчанию 30) фото одновременно.
Если регулярно копится больше — увеличьте это значение в
`generate_feed.py` или запускайте workflow вручную чаще, чем раз в день.

Группировка не идеальна — иногда нейросеть может ошибочно
объединить/разделить фото. Если увидите неправильную группу в
опубликованном посте — просто добавьте недостающее фото повторно в
`to_post` со следующей партией, а лишнее фото из чужого поста можно
проигнорировать (оно уже уедет в `posted`, не будет мешать дальше).

## Что нужно один раз настроить

### 1. Папки на Яндекс.Диске
`to_post` и `posted` в корне. Внутри `to_post` — просто фото, без
подпапок.

### 2. Токен Яндекс.Диска
https://oauth.yandex.ru/client/new → права **Яндекс.Диск REST API** →
получить `YANDEX_TOKEN` через
`https://oauth.yandex.ru/authorize?response_type=token&client_id=...`

### 3. Ключ OpenRouter
https://openrouter.ai → Keys → создать ключ — `OPENROUTER_API_KEY`

### 4. Telegram-канал и бот
Канал `@customstudio_print`, бот `@cstmstd_autopost_bot` (уже созданы),
бот должен быть администратором канала. `TELEGRAM_BOT_TOKEN` и
`TELEGRAM_CHANNEL` (`@customstudio_print`).

### 5. Репозиторий на GitHub + GitHub Pages
1. Публичный репозиторий
2. Файлы: `generate_feed.py`, `requirements.txt`, `README.md`,
   `.github/workflows/daily-post.yml`, `docs/.gitkeep`
3. Settings → Pages → Source: Deploy from a branch → main → `/docs` → Save
4. Скопировать адрес сайта → `SITE_BASE_URL`
5. Settings → Secrets and variables → Actions → пять секретов:
   `YANDEX_TOKEN`, `OPENROUTER_API_KEY`, `SITE_BASE_URL`,
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL`

### 6. Настройка VK
Группа → Управление сообществом → Настройки → Дополнительно → RSS:
- «Импорт в сообщество» — включено
- Ссылка на файл: `SITE_BASE_URL/feed.xml`
- Галочку «Публиковать в виде статьи» — **не ставить** (оставить как
  обычный импорт, одно фото-обложка на пост)

## Автотесты

```
python3 tests/run.py
```

Проверяют загрузку картинок для текстовых рубрик: отсев форматов, которые
Telegram не принимает (svg, gif), повторные попытки при протухших ссылках и
приоритет папки `rubrics/holidays` для праздничных постов. Сеть, ключи и
Яндекс.Диск подменяются заглушками — запускать можно где угодно, ничего
никуда не опубликуется.

## Проверка

1. Закиньте в `to_post` 2-4 тестовых фото (можно одного товара, можно
   разных — проверите, как нейросеть их разгруппирует)
2. Actions → Daily VK Post → Run workflow
3. Проверьте лог запуска — там будет видно, как нейросеть разбила фото
   на группы, и какая группа выбрана для этого поста
4. Пост должен появиться в Telegram-канале; `docs/feed.xml` обновится;
   фото выбранной группы переедут в `posted`, остальные останутся в
   `to_post` до следующего запуска
5. Публикация в VK не мгновенная — зависит от расписания проверки VK
